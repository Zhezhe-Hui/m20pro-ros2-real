- 辅助遥控

本文档描述山猫 M20 辅助模式（使用模式=2）下的避障辅助遥控能力。在辅助模式下，开发者通过手柄或协议下发速度指令，机器人会自动结合激光雷达感知结果进行避障修正，输出安全的实际运动速度。目录1. 概述2. 辅助模式开启 —— basic_server 协议3. 速度指令与避障修正 —— basic_server 协议4. 避障状态与错误码5. 安全注意事项﻿﻿
# 1. 概述
辅助模式（ControlUsageMode = 2）是介于手动遥控和自主导航之间的一种使用模式：●操控方式：由开发者或操作员通过手柄/协议下发速度指令（轴指令 Type=2 Cmd=21）●避障能力：机器人实时感知前方障碍物，自动修正速度以避免碰撞●适用场景：人机共融环境、半自主巡检、遥控穿越复杂地形
### 工作模式对比
| 模式 | 使用模式值 | 操控方式 | 避障能力 |
|---|---|---|---|
| 常规模式 | 0 | 手柄/协议直接控制 | 无自动避障 |
| 导航模式 | 1 | 自主导航规划 | 实时局部避障 |
| 辅助模式 | 2 | 手柄/协议控制 + 自动避障修正 | 实时局部避障 |﻿﻿
# 2. 辅助模式开启 —— basic_server 协议

## 2.1 切换至辅助模式
通过 Type=1101 Cmd=5 切换使用模式：复制代码9912345678910▶▶▶▶{ "PatrolDevice": { "Type": 1101, "Command": 5, "Time": "2026-05-20 10:00:00", "Items": { "Mode": 2 } }}模式切换成功后，机器人进入辅助模式。此时下发的速度指令（Type=2 Cmd=21）将自动经过避障模块修正。﻿
## 2.2 确认当前模式
订阅 Type=1002 Cmd=6 的 ControlUsageMode 字段确认：| ControlUsageMode | 含义 |
|---|---|
| 0 | 常规模式 |
| 1 | 导航模式 |
| 2 | 辅助模式 |﻿﻿
# 3. 速度指令与避障修正 —— basic_server 协议
在辅助模式下，速度指令通过运动控制-轴指令（Type=2 Cmd=21）下发，格式与常规模式完全相同，区别在于底层会自动叠加避障逻辑。
## 3.1 速度指令格式
复制代码99123456789101112131415▶▶▶▶{ "PatrolDevice": { "Type": 2, "Command": 21, "Time": "2026-05-20 10:00:00.050", "Items": { "X": 0.8, "Y": 0.0, "Z": 0.0, "Roll": 0.0, "Pitch": 0.0, "Yaw": 0.0 } }}| 字段 | 类型 | 范围 | 含义 |
|---|---|---|---|
| X | float | [-1, 1] | 前进/后退（归一化百分比） |
| Y | float | [-1, 1] | 左移/右移（归一化百分比） |
| Yaw | float | [-1, 1] | 偏航角速度（归一化百分比） |●发送频率：建议 20Hz●传输方式：推荐使用 UDP（端口 30000）以获得最低延迟﻿
## 3.2 避障修正行为
全向避障模块结合障碍物点云，判定机器人在当前输入速度下是否会碰撞，继而输出避障速度：| 场景 | 行为 |
|---|---|
| 前方无障碍物 | 正常执行手柄输入速度 |
| 前方有障碍物 | 输出避障速度（减速或绕行） |
| 障碍物过近 | 自动停止，防止碰撞 |具体的减速策略和距离阈值由底层避障算法根据点云密度、障碍物尺寸和当前速度动态计算。﻿﻿
# 4. 避障状态与错误码

## 4.1 ROS2 话题：/OOA_STATUS
避障模块的运行状态通过 /OOA_STATUS 话题发布 state 字段，可在 31 和 33 网段订阅：复制代码91▶ros2 topic echo /OOA_STATUS
### 状态码（state）
| 十六进制值 | 含义 |
|---|---|
| 0x00 | 未启动 |
| 0x01 | 已启动，空闲中（没有轴指令输入） |
| 0x02 | 已启动，无障碍物 |
| 0x03 | 已启动，避障中 |﻿/OOA_STATUS 话题仅包含 state 字段。如需同时查看错误码，请参见下方 handler 服务日志。﻿
## 4.2 handler 服务日志
handler 服务周期性输出状态与频率信息，日志中包含 state 和 error_code 两个字段，分别对应状态码和错误码：复制代码912▶# 查看 handler 服务日志sudo journalctl -u handler.service -f日志格式示例：复制代码91▶Data freq(Hz): Steer=0 Odom=0 IMU=200 Cloud=0 state:0 error_code:0| 日志字段 | 说明 |
|---|---|
| ﻿Steer﻿ | 转向指令实际频率 (Hz) |
| ﻿Odom﻿ | 里程计实际频率 (Hz) |
| ﻿IMU﻿ | IMU 实际频率 (Hz) |
| ﻿Cloud﻿ | 点云实际频率 (Hz) |
| ﻿state﻿ | 避障状态码 |
| ﻿error_code﻿ | 避障错误码 |当某个输入话题的实际频率为 0 时，通常意味着对应的传感器或模块未正常工作，可结合错误码进行排查。
### 错误码（error_code）
| 十六进制值 | 含义 | 建议动作 |
|---|---|---|
| 0x00 | 无错误 | — |
| 0x01 | 无手柄速度输入 | 检查是否已下发 Type=2 Cmd=21 轴指令 |
| 0x02 | 无点云输入 | 检查激光雷达是否正常工作 |
| 0x03 | 无里程计输入 | 检查定位模块是否正常运行 |
| 0x04 | 无 IMU 输入 | 检查 IMU 是否正常 |
| 0x05 | 计算超时 | 检查 CPU 负载或降低环境复杂度 |出现非零错误码时，避障功能可能出现异常，应根据错误码排查对应传感器或模块。﻿
## 4.3 basic_server 协议：Type=1002 Cmd=6 OOA 字段
﻿Type=1002 Cmd=6 BasicStatus 上报中包含 OOA 字段，可直接读取避障状态码：●OOA 状态码：含义与 /OOA_STATUS 话题的 state 字段一致（0x00~0x03）﻿﻿
# 5. 安全注意事项
1.急停优先：在紧急情况下，不要依赖避障系统，应直接发送软急停（Type=2 Cmd=22 MotionParam=2）或触发硬急停。2.传感器依赖：避障能力依赖于激光雷达和 IMU 的正常工作。确保相关设备已启用（参考设备与传感器概览）。3.环境限制：避免在天花板高度低于 1 米的区域使用辅助模式，以免天花板被误判为障碍物。相关文档：使用模式管理| 运动控制（basic_server 协议）﻿大纲辅助遥控1. 概述工作模式对比2. 辅助模式开启 —— basic_server 协议2.1 切换至辅助模式2.2 确认当前模式3. 速度指令与避障修正 —— basic_server 协议3.1 速度指令格式3.2 避障修正行为4. 避障状态与错误码4.1 ROS2 话题：/OOA_STATUS状态码（state）4.2 handler 服务日志错误码（error_code）4.3 basic_server 协议：Type=1002 Cmd=6 OOA 字段5. 安全注意事项
