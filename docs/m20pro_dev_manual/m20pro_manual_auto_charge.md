- 自主充电

自主充电是巡检系统的核心闭环。在导航任务过程中执行自主充电，请参考导航任务下发中的单点任务下发指令，以充电点形式下发即可。本章仅说明直接调用自主充电功能（需确保机器人已到达充电桩前）的使用细节，并提供 basic_server、ROS2 等多种接入方式。自主充电为选配功能。﻿目录1. 系统架构1.1 数据流1.2 状态机2. 充电指令下发2.1 basic_server 协议（Type=2, Command=24）2.2 ROS2 接口3. 充电状态推送3.1 basic_server协议 （Type=1002, Command=6）3.2 ROS2 接口﻿﻿

# 2. 充电指令下发

## 2.1 basic_server 协议（Type=2, Command=24）
JSON 请求复制代码91234567▶▶▶{ "PatrolDevice": { "Type": 2, "Command": 24, "Time": "2026-05-20 10:00:00", "Items": { "Charge": 1 } }}XML 等价复制代码912345678▶▶▶<?xml version="1.0" encoding="UTF-8"?><PatrolDevice> <Type>2</Type><Command>24</Command> <Time>2026-05-20 10:00:00</Time> <Items> <Charge>1</Charge> </Items></PatrolDevice>字段说明| 字段 | 类型 | 取值 | 含义 |
|---|---|---|---|
| Charge | int | 0=退出充电 | 停止当前充电并退桩 |
| Charge | int | 1=开始充电 | 启动自主充电流程 |
| Charge | int | 2=重置 | 强制恢复空闲状态 |⚠️ 警告：Charge=2 为强制清除充电状态操作，存在风险。建议仅在充电状态异常且无法正常结束充电时使用。正常使用应通过 Charge=0 结束充电。﻿

|---|---|
